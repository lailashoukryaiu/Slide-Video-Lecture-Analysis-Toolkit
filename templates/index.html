Slide detection options

More keeps every build step, Balanced merges small bullet builds, and Fewer merges all builds and quick flips. Full slide changes are kept at every level, so decks without builds can give the same count.
Lower values detect more hard cuts. Higher values detect fewer cuts.
Scales with the video, with a 2 s floor for short clips. A fixed limit applies to every detail level, so a low limit can make all levels return the same count. Short clips may include up to 10 slides; when the limit is reached, the most distinct changes are kept.
Adaptive mode finds settled slide states, ignores cursor and webcam movement, and merges builds according to the detail level.
